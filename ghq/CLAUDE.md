# Общие инструкции

Перед работой с репозиториями в этой папке прочитай и соблюдай соседний
`AGENTS.md`, затем инструкции конкретного проекта.

Общий порядок: план → изменения → тесты и сборка → независимое ревью →
проверка веб-интерфейса, если он затронут → разрешённые коммит, PR и CI.

Для `pvs-efs-assist` (бывшего Graph), включая его зеркала, действуют отдельные
правила закрытого сегмента из инструкций проекта. Не объявляй его полную
сборку и тесты подтверждёнными по локальным проверкам.

Навыки Matt Pocock используй выборочно по разделу «Навыки Matt Pocock»
в `AGENTS.md`. Они не разрешают автоматические коммиты, публикацию задач
и отправку изменений и не отменяют ограничения закрытого сегмента.
